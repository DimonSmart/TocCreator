# IDD-0001.spec-source-document-and-markdown-export

## Intent

Convert already extracted book text into Markdown whose chapter and section
structure is recovered without rewriting the book text.

## Related Specifications

- IDD-0002
- IDD-0003

## Behavior

- The application accepts text that was extracted from a PDF or another source.
  Extracting PDF text itself is outside the product.
- Import creates an immutable source snapshot and deterministically segments it
  into ordered, addressable text pointers. Pointer identifiers remain stable for
  the lifetime of that imported snapshot.
- Each pointer records its source span and may include its source page when that
  information is available. Segmentation preserves enough information to
  reconstruct the source text exactly.
- Structural annotations are stored separately from source text. A pointer is
  `Body`, `Heading`, `Toc`, or `Noise`; a heading has a level from 1 through 3
  and every other role has no heading level.
- Markdown export walks pointers in source order. It emits the original source
  span for body text, prefixes headings with one to three `#` characters based
  on their annotation, and omits pointers annotated as noise. It preserves an
  existing table of contents by default.
- Heading text always comes from the associated body source span. Table-of-
  contents text is never copied into the body to create a heading.
- Re-exporting identical source and annotations produces identical Markdown.

## Product-Significant Architecture And Constraints

After import, source text and its offsets are immutable. Structural recovery
changes annotations only; it never rewrites, deletes, or inserts book text.

## Non-goals

- PDF extraction, OCR, and source-text cleanup.
- Restoring emphasis, tables, lists, images, links, footnotes, quotations,
  mathematics, or paragraph formatting beyond headings.
- Rewriting, stylistically editing, grammar-correcting, or inventing book text.
- Generating a new table of contents.

## Acceptance Criteria

- Chapters, sections, and subsections can be exported as Markdown levels 1, 2,
  and 3 respectively.
- Confirmed noise is absent from the export while remaining present in the
  immutable source snapshot.
- Export does not require an LLM call.

## Verification

- Verify that a source span annotated as a level-1, level-2, or level-3 heading
  is rendered with the matching Markdown prefix and unchanged text.
- Verify repeat export determinism and source preservation.
