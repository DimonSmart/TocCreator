# IDD-0002.spec-toc-and-structural-discovery

## Intent

Recover book structure from extracted text, using an existing table of contents
as a strong reference when it is available and supporting books that lack one.

## Related Specifications

- IDD-0001
- IDD-0003

## Behavior

- The application looks for a table of contents near the start of the document
  using deterministic signals, including common contents labels, repeated short
  lines, page numbers, chapter patterns, and regular numbering.
- It examines only small candidate ranges to decide whether they are a table of
  contents, then parses accepted ranges into entries with a source pointer,
  title, level 1 through 3, and an optional printed page number.
- A table of contents is a structural reference, not the authority for body
  text. Matching tolerates ordinary case, punctuation, numbering, and OCR
  differences, while preserving expected order and using an approximate page
  match when available.
- An unambiguous deterministic match is accepted without a semantic call. An
  ambiguous match is resolved from local candidates, nearby context, current
  structure, and the next expected entries.
- When no table of contents exists, structure is recovered from deterministic
  heading candidates, current structure, numbering patterns, and local text.
- Candidate detection considers short isolated blocks, whitespace, chapter,
  part, appendix, and hierarchical numbering patterns, TOC similarity, and
  recurring heading patterns. Ordinary body paragraphs are not presented as
  heading candidates merely because they are in a scan range.
- Introduction, preface, appendix, references, and comparable parts receive
  level 1 when their structural rank equals a chapter.
- The application detects page numbers, repeated running headers, repeated
  chapter titles, and repeated footers as noise candidates. It may confirm clear
  cases deterministically and resolves uncertain cases using only local context
  and repetition evidence.

## Product-Significant Architecture And Constraints

Semantic decisions refer to existing pointer identifiers, never copied or
rewritten book text. The application validates that returned identifiers exist,
were supplied to the operation, and are eligible for the requested decision.

## Non-goals

- Treating a table of contents as a replacement source for body headings.
- Marking every block with a body-versus-heading classification.

## Acceptance Criteria

- Exact and punctuation-different TOC entries can be matched to the correct
  body pointers without inserting TOC titles into the body.
- A printed page number cannot become body-heading text.
- Repeated running headers are not promoted to chapters.

## Verification

- Verify books with exact and punctuation-different TOCs, page numbers,
  repeated headers, appendices, and no TOC.
- Verify that a result containing an unknown pointer identifier is rejected.
