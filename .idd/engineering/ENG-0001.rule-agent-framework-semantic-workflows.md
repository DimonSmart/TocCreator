# ENG-0001.rule-agent-framework-semantic-workflows

## Rule

Implement semantic operations with Microsoft Agent Framework as an explicit,
checkpointable workflow of ordinary executors and narrowly scoped agent
executors with typed inputs and results.

## Applicability

Always

## Rationale

The workflow must retain application ownership of book state and keep each
local-model decision small, auditable, and independently retryable.

## Guidance

- Give each agent executor one semantic responsibility; do not create generic
  manager, coordinator, or memory agents without a distinct narrow role.
- Keep deterministic segmentation, pointer allocation, window ownership,
  checkpointing, validation, annotation application, retries, and Markdown
  export in ordinary application code.
- Use typed framework results or typed tool/function calls instead of a
  hand-built general parser for model output.

## Verification

Evidence shows that each semantic operation has a narrow typed contract and
that deterministic workflow state transitions remain application-controlled.
