# ENG-0002.rule-provider-neutral-openai-compatible-integration

## Rule

Integrate language models through an OpenAI-compatible API and keep business
logic independent of a specific local-model runtime.

## Applicability

Conditional

## Applies when

- adding or modifying model-provider integration or model profiles

## Rationale

The product targets local small models while allowing compatible providers to be
substituted without changing structural-recovery business logic.

## Guidance

- Model profiles expose the configured endpoint, model, credentials, JSON Schema
  inclusion, structured-output support, and temperature support.
- Use provider-side structured output when supported, and retain application-side
  validation for every result.

## Verification

Evidence shows that switching between OpenAI-compatible providers does not
require changes to structural-recovery business logic.
